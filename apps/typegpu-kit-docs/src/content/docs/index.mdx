## What it is

TypeGPU Kit provides GPU modules in one package, `@typegpu/kit`. It uses [TypeGPU](https://typegpu.com) in WebGPU browsers and React Native. Each module borrows your root and records into the passes you give it. You own the loop, frame and canvas. [How the kit works](/concepts/how-the-kit-works/) sets it beside plain WebGPU and TypeGPU.
